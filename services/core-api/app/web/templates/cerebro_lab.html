Entrada

El texto se normaliza (números, cédulas, dinero) y el LLM solo propone hechos con cita. El backend descarta lo que no está sostenido por el texto.
Arrastra un audio aquí o haz clic para elegirlo
ogg · opus · mp3 · m4a · wav · webm
Grabar desde el micrófono usa MediaRecorder; el audio va a Groq/Whisper y luego al Cerebro. Nada se escribe en la base de negocio.
El navegador no dio acceso al micrófono

  1. En Chrome o Edge: pulsa el candado junto a la dirección → Micrófono → Permitir.
  2. Recarga la página (F5).
  3. Si sigue igual: Windows → Configuración → Privacidad y seguridad → Micrófono → permitir el acceso a las aplicaciones.
  4. Si esta ventana es la vista previa de una app de escritorio, ábrela en Chrome o Edge: esa vista previa bloquea el micrófono.

Mientras tanto puedes arrastrar una nota de voz: se transcribe igual.

Resultado

Todavía no hay nada. Escribe un dictado o sube un audio y pulsa el botón.

Lo que entendí

Si algo está mal, usa «Corregir» en el hecho correspondiente. La corrección rehace el borrador; no se pierde nada de lo anterior.
