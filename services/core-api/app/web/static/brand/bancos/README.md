# Logos de bancos

Se usan **solo para identificar** las cuentas en la cabecera de Banca y Mercado.
Son marcas registradas de sus titulares; no se modifican ni se usan como marca
propia.

Cada archivo es una placa de 96×96 px con el color de marca del banco y su
isotipo, para que se lea a 46 px en la tarjeta:

| Archivo | Banco | Fondo | Isotipo |
|---|---|---|---|
| `pichincha.svg` | Banco Pichincha | Amarillo `#FFD100` | Cuadrado azul `#1B2D54` (vector original) |
| `guayaquil.svg` | Banco Guayaquil | Rosado `#C7007E` | Anillo blanco (isotipo oficial, blanco sobre transparente) |
| `internacional.svg` | Banco Internacional | Naranja `#F39200` | Barras blancas (geometría medida del logo oficial) |

`internacional.png` se conserva como fuente original del logo; el panel usa el
`svg` para que las barras queden nítidas en cualquier pantalla.

Si Dirección entrega los logos oficiales en alta resolución, se reemplazan
estos archivos conservando el mismo nombre.
