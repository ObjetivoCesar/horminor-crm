## Bloque A — Conectar Evolution API (WhatsApp)

| # | Paso | Criterio de aceptación |

## Bloque B — Bunny.net Storage + token

| # | Paso | Criterio de aceptación |
|---|---|---|
| B1 | Confirmar Storage Zone, región y Pull Zone de Horminor | Zona creada y visible en el file manager |
| B2 | Cargar `storage_zone`, `api_key`, `cdn_host` y `token_key` en **Superadmin > Bunny** (o `.env`: `BUNNY_STORAGE_ZONE`, `BUNNY_STORAGE_API_KEY`, `BUNNY_CDN_HOST`, `BUNNY_TOKEN_KEY`) | La API los lee |
| B3 | Activar **Token Authentication** en el Pull Zone de Bunny (Security) | El CDN exige `?token=&expires=` |
| B4 | Poner `sandbox = false` en `integraciones.bunny` | La próxima subida va a `BUNNY`, no al sandbox |
| B5 | Subir una foto desde el clip del chat | Aparece en `clientes/<nombre>_<cedula>/` y se ve en el hilo |
| B6 | Abrir la URL del CDN sin token | Debe responder 403; con el token firmado, 200 |

La firma se genera en `app/services/media.py::firmar_url_bunny()`. Si `BUNNY_TOKEN_KEY` queda vacía, las URLs salen públicas: eso es solo para local.
