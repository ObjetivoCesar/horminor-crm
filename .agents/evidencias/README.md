# Evidencias

Aquí se guardan las salidas **completas** de comandos, tests y diagnósticos que
son demasiado largos para la bitácora.

## Convención de nombre

```
AAAA-MM-DD_descripcion_corta.txt
```

Ejemplos:

- `2026-11-08_pytest_completo.txt`
- `2026-11-08_hito1_lock_test.txt`
- `2026-11-09_centinela_daily_audit.json`

## Regla

- La bitácora guarda la **conclusión** y cita la ruta del archivo.
- Aquí va el volcado crudo, sin editar. Si algo falló, el fallo también se guarda.
- Nada de secretos: si la salida trae claves o tokens, se redactan antes de
  guardar.
- Estos archivos no se versionan por defecto (ver `.gitignore`), salvo que sean
  evidencia de un cierre de hito.
